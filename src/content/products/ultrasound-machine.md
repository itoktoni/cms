## Fitur Utama

Ultrasound System X500 adalah solusi imaging lengkap untuk berbagai kebutuhan diagnostik. Dilengkapi dengan multiple probe support dan teknologi AI untuk membantu proses pemeriksaan.

## Spesifikasi Teknis

| Parameter | Spesifikasi |
|-----------|-------------|
| Transducer | Multi-frequency 2-18 MHz |
| Display | 21.5" Full HD LED |
| Image Modes | B, B/B, 4B, M, B/M, PW, CFM, PDI, DTI |
| Measurements | Auto, Manual, Trace, Calculation Packages |
| Storage | 500GB SSD + Cloud |

## Keunggulan

- **Teknologi AI**: Bantuan pengukuran otomatis untuk meningkatkan akurasi
- **Multi-Probe**: Mendukung berbagai jenis probe untuk aplikasi berbeda
